# New Game

This directory is the canonical shared design area for the game project currently referred to as **New Game**.

## Source of truth

- `MASTER_DESIGN.md` — authoritative current game design document.

Future ChatGPT/agent work should read `new-game/MASTER_DESIGN.md` before making design decisions and should update that file when decisions are explicitly locked in.

## Working conventions

- Treat names such as **The Concordance**, **The Loom**, and **The Curator** as placeholders unless the master design says otherwise.
- Preserve the distinction between **locked design direction** and **open questions**.
- Do not create separate competing master documents unless intentionally archiving a milestone.
- When a design decision changes, update the relevant existing section rather than only appending a note.

Current project identity/title is not final. Candidate naming directions explored so far include **A Seam of Time** and **Of Feather and Stone**.
